✊ Rock Paper Scissors Game

A simple and interactive Rock Paper Scissors Game built using HTML, CSS, and JavaScript. Play against the computer, check the results, and track your score!

🚀 Live Demo

Run the project locally using your browser or VS Code Live Server.

✨ Features

- ✊ Rock, Paper, and Scissors choices
- 🎲 Random computer moves
- 🏆 Automatic winner detection
- 📊 Running score display
- 🤝 Draw counter
- 🔄 Reset game functionality
- 📱 Responsive user interface

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

📂 Project Structure

Rock_Paper_Scissors/
├── index.html
├── style.css
├── script.js
└── README.md

🎮 Game Rules

- Rock beats Scissors.
- Scissors beats Paper.
- Paper beats Rock.
- Identical choices result in a draw.

💻 How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Ensure all three files are in the same folder.
4. Open "index.html" using Live Server.
5. Choose Rock, Paper, or Scissors and enjoy the game!
